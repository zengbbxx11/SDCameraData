# DC325W 待核实事项

| 事项 | 当前情况 | 需要确认 |
| --- | --- | --- |
| 英文型号 | 中文写作 DC325W，英文一处写作 D325W | 确认是否为同一型号 |
| 变焦 | 现有参数只明确标注 8 倍数字变焦 | 是否具备光学变焦 |
| 插值 | 96 MP照片及5K/8K视频标有插值；其他档位未明确 | 是否需要补充各档定义 |
| 存储 | 英文规格最大扩展容量为 1 TB；同表另列 SDHC Class 6 | 确认 SDHC Class 6 与 1 TB 上限是否同时适用，以及实际支持的卡型 |
| 内置闪存 | 存储章节将字段写作“存储卡”，值为“闪存：N / A” | 确认字段实际含义及闪存是否存在 |
| 镜头标注 | 光圈与焦距写作“Ff(F=1.8；f=4.7 mm)”，另列实际标注“F=1.79±0.5%；f=4.694 mm” | 确认规范写法及两组数值的关系，不覆盖原候选 |
| 随箱镜头盖 | 一份规格包含镜头盖，其他配置清单未列 | 确认适用的实际包装 |
| 电池 | 不同配置记录了不同 NP-60 料号 | 确认实际订单或批次使用的料号 |
| 配置关联 | 5K/8K规格与品牌配置没有完整绑定关系 | 只有确认后才建立实际销售配置 |
| 参数表格式 | 照片档位明细为3列、视频档位明细为5列 | 按统一“参数｜参数值”格式整理，同时保留像素、尺寸、方案、帧率和插值信息 |
