# DC417X 待核实事项

| 事项 | 当前情况 | 需要确认 |
| --- | --- | --- |
| 电池参数 | 不同配置出现 NP-40 1050 mAh、NP-40 PLUS 1050 mAh及“850MA” | 确认型号及容量单位；“850MA”暂不换算 |
| 电池替换 | 一项配置记录了清库存后更换电池料号 | 确认新旧料规格及适用批次 |
| 品牌包装 | 彩族、初步配置暂未建立包装清单 | 有实际包装资料后补录，不继承其他配置 |
| 转接头 | 国外配置中出现“国内出货配件”说明 | 确认是否适用于国外订单 |
| 缓存单位 | 记录为 4 Gb DDR3 | 确认单位；不得改写为 4 GB |
| 内置闪存 | 机身存储容量写“闪存：N / A” | 确认是无内置闪存、不适用还是未提供，并明确字段含义 |
| 视频档位插值 | 视频档位未注明原生或插值方式 | 确认各视频档属性，未确认前不推定 |
| 规格与配置关联 | 规格与品牌、生产批次尚未绑定 | 确认后再补充实际销售配置 |
| 照片档位插值 | 88 MP明确标注插值，其他照片档未注明原生或插值 | 确认各档生成方式，未确认前不推定 |
| 参数表格式 | 视频档位明细为4列、照片档位明细为3列 | 按统一“参数｜参数值”格式整理，同时保留档位、帧率和插值信息 |
| 参数归类 | “存储”章节内列有“电池容量”，与参数类别不符 | 确认是否误置及正式归类；不据此改动电池数值 |
| 参数文字格式 | 出现“关//自动闪光”“Win 10//Win 11”“1 /3840秒”等异常分隔或空格 | 核对并统一文字与符号格式，保留实际参数含义 |
