# 个人产品知识库

当前目录就是 Obsidian Vault 和本地 Git 根目录。入口是 [[首页]]，不需要额外服务、社区插件或数据库。支持 Obsidian 核心 Bases 的版本可显示卡片与表格，普通 Markdown 链接和全文参数始终可读。

## 如何查看

1. 在当前 Vault 打开“首页”，进入 DC325W、DC417X 或 BK05。
2. 主档直接嵌入实际参数速览；点技术规格查看完整参数、中英文原值、视频档位、原始单元格。
3. 打开“规格对比”“品牌包装对比”横向查看；点包装物料编号进入唯一共用档案。
4. 首页的待核实和资料缺失入口用于补资料。空报价、认证、销售配置视图是尚无符合条件记录，不是假数据。
5. 在个人备注页自由写心得。用 Obsidian 重命名笔记时允许自动更新内部链接，重要实体编号不变。

## 如何继续

“整理产品 XXX”：先查原目录文件名和必要内容，写导入计划，明确内容直接建档，不确定内容保留候选。

“更新产品 DC325W”：先读当前档案与人工修改，按来源指纹对比变化，生成字段差异，保留历史和已核实关键数据，再更新相关摘要及链接。

“确认 ISSUE-DC325W-xx，结论……，依据……”：记录确认人/日期/依据，更新关联参数及对比，保留原始候选。

目录规则、稳定编号、参数别名见 [[数据模型与维护规则]]、[[参数名称与别名]]。新增品类主要复制90_模板内相应品类模板，复用通用分组，有来源才填值。

## 数据与同步

来源位置及证书根统一在 [[资料来源与本机配置]]。原始Excel/PDF/Word只读，不在Vault复制原文件。所有Markdown摘录也可能含公司内部信息。

本地Git未配置远程，不自动上传或提交。.gitignore不能阻止历史敏感文件被上传。未来云同步前检查完整历史与同步范围；需要仅同步获准资料时另行导出到干净目录，不复用含敏感数据历史。完整Vault可备份到公司批准的本地介质，外部原始资料需另行备份。

原有Obsidian Sync插件为启用状态，未改变配置，是否已连接云端需在应用设置中人工检查。现有用户设置保留。

## 验证范围

本轮执行Markdown/YAML/Bases、编号、内部链接及来源覆盖检查。未通过图形界面确认所有卡片、表格列宽及链接跳转。请在Obsidian打开首页检查视觉效果；Bases格式参考 [Obsidian官方语法](https://help.obsidian.md/bases/syntax) 和 [嵌入视图](https://help.obsidian.md/bases/create-base)。

## 当前默认界面

以国外业务为主，国内和候选资料在产品页折叠入口保留。零部件显示中文名称＋料号，原料号可通过别名查找。

全局图谱默认筛选 `[图谱层级:主线]`，当前12个节点，四色区分产品、规格、商业配置和包装。清空筛选可恢复全库图谱；局部图谱有自己的筛选，可先设深度1。

如果已打开的图谱仍显示旧样式，关闭图谱标签后重开；必要时重新打开Vault以重新载入配置。筛选只改变显示，不删除资料。连线表示引用，不表示已确认的销售组合。

设置依据 [Obsidian图谱说明](https://help.obsidian.md/plugins/graph)。本轮通过文件级检查，未完成图形界面验收。

## 目录层级

- 产品相关模块采用“模块/产品型号/笔记”：产品主档、技术规格、品牌配置、修订、包装、来源、问题和个人备注均按DC325W、DC417X、BK05等型号或已确认系列归组。
- 共用零部件按用途分为电池、线材与转接、说明书与卡片、标签与保护膜、薄膜与包装袋、内托与纸卡、包装盒与外箱、收纳与携带、清洁用品。共用料不按产品复制；物料分类属性与目录一致。
- 模板分为通用、品类参数、业务模板；变更记录按YYYY-MM归档。跨产品检索说明留在来源模块根目录。只建立实际有文件的子目录。
- 报价将来按客户/项目管理，跨产品报价保留一份；认证按实际适用范围管理，不为每个产品复制证书。当前无真实记录时不建立空子目录。
- 文件移动保留文件名、稳定ID和别名，检查显式路径、Obsidian打开页面引用、Bases及图谱筛选。当前短名称内部链接可跨子目录解析。
