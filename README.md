# 个人产品知识库

打开 [[首页]]，从产品画册进入型号主页。产品资料写在 Markdown 中，不需要额外程序。

## 整理产品

告诉我“整理产品 XXX”或“更新产品 XXX”。我会读取 [[本机资料目录与配置]] 中的原始资料，把整理后的参数、品牌配置和包装信息写入对应页面。公司原文件只读，Vault 不保存原文件链接和逐项摘录。

产品主页查看参数速览，并直接展示配件、包装盒尺寸、外箱尺寸与装箱规格；完整参数和方案差异仍在同一规格页维护。品牌配置和实际包装清单作为补充明细。个人心得写在对应的个人备注页。

[[产品配件与包装]] 按型号进入上述参数和实际包装清单；料号查询放在折叠区，需要查某项配件或包材的详细规格时再进入。

整理海外产品时优先采用标明国外/海外的资料；同一配置有中英文表时按英文表记录。国内资料只补充缺项或协助核对，冲突交由待确认事项处理。

## GitHub

配置的仓库是公开的。上传前先确认公司允许公开这些资料。删除本地文件不会删除远端副本或 Git 历史。

## 更换电脑

在 [[本机资料目录与配置]] 更新原始资料和证书的本机路径。

## 页面显示

首页自动汇总产品，可切换卡片、品类和国外优先视图。产品页顶部可直达参数、包装和待确认事项；完整度读取产品属性，不另填一份表格。

产品主页先看参数速览；详细参数可在本页展开，照片和视频档位及方案差异一并保留，也可直接进入规格页。已有产品图片在规格页集中维护，主档嵌入显示，产品画册使用同一图片作为封面。产品参数以参数表为准。图片仅供外观参考，图中丝印不准确，不作为参数依据，也不列作参数冲突待核实。[[型号比较]] 提供 DC105／DC105PRO、GO7／GO9 的同屏查看，内容嵌入规格页，比较页不另存参数。其他型号可从技术规格查询选择后，在两个标签组中分别打开。

待确认事项可按型号和未解决问题数查看。清单只保留需要资料或实机判断的问题；已完成的排版修复写入变更记录，不继续占用待确认清单。

## 回溯与更新

需要回查时，从 [[本机资料目录与配置]] 进入公司资料副本，先按型号及已有别名查找，再区分规格、品牌、地区和修订。证书相对目录也以公司资料副本为根目录。本机副本的日期只表示资料截点，不能证明当前产品仍采用该配置；新资料仍需按同一方案核对，不凭文件日期覆盖。

当前 Vault 没有逐项出处索引。按现有规则，原文件链接、页码和单元格定位不写入正式页；待核实事项保留冲突含义，重要更新在变更记录中简述。参数更新时一并核对同页速览；产品主页和比较页的嵌入随规格页更新。

阅读模式使用“产品资料阅读”样式：加宽表格、隐藏页首系统属性。编辑属性时切到编辑模式；也可在“设置 → 外观 → CSS代码片段”关闭该样式。正文和链接不依赖样式。

附件按“附件/产品型号”保存，使用包含型号和用途的中文文件名。同一图片只保存一份，通过链接或嵌入复用；本次整理的图片保留参数表内嵌原图，未改动像素。新增图片先检查适用方案和已有附件；视频资料有明确内容后再加入，不建立空资料页。
