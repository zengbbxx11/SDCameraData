# 个人产品知识库

打开 [[首页]]，从产品画册进入型号主页。产品资料写在 Markdown 中，不需要额外程序。

## 整理产品

告诉我“整理产品 XXX”或“更新产品 XXX”。我会读取 [[本机资料目录与配置]] 中的原始资料，把整理后的参数、品牌配置和包装信息写入对应页面。公司原文件只读，Vault 不保存原文件链接和逐项摘录。

产品主页查看概况；完整参数、品牌配置和包装清单按产品分别查看。个人心得写在对应的个人备注页。

## GitHub

配置的仓库是公开的。上传前先确认公司允许公开这些资料。删除本地文件不会删除远端副本或 Git 历史。

## 更换电脑

在 [[本机资料目录与配置]] 更新原始资料和证书的本机路径。

## 页面显示

首页自动汇总产品，可切换卡片、品类和国外优先视图。产品页顶部可直达参数、包装和待确认事项；完整度读取产品属性，不另填一份表格。

阅读模式使用“产品资料阅读”样式：加宽表格、隐藏页首系统属性。编辑属性时切到编辑模式；也可在“设置 → 外观 → CSS代码片段”关闭该样式。正文和链接不依赖样式。
