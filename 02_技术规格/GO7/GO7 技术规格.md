| HDR | 支持 |
| WDR | 支持 |

| 参数 | 参数值 |

| 手机应用 | Viipulse，支持 Android 和 iOS |
| 充电与接口 | Type-C / OTG；主机与拓展舱支持顶针充电 |
| 状态灯 | LED充电／工作指示灯 |
