# DC226 技术规格

[[DC226|返回产品]] · [[#视频档位|视频档位]] · [[#照片档位|照片档位]] · [[#前置规格|前置规格]]

产品：[[DC226]]。当前仅采用Sony IMX689、1/1.4英寸大底传感器规格。

## 参数速览

| 参数 | 参数值 |
| --- | --- |
| 前置传感器 | Sony IMX689，48 MP，1/1.4英寸大底 |
| 后置自拍传感器 | IMX386，12 MP |
| 最高视频档位 | 8K 15 fps |
| 最高照片档位 | 88 MP，插值 |
| 产品带电重量（不含镜头盖） | 468.6 g |
| 显示屏 | 3.2英寸IPS触摸屏，1024 × 768 |
| 变焦 | 16倍数字变焦；不具备光学变焦 |
| 电池 | NP-80，实际容量1500 mAh；丝印与证书容量均为1220 mAh（反向虚标）；详见 [[NP-80英文标贴电池（500-8001-00）]] |
