# GO9 技术规格

[[GO9|返回产品]]


## 参数速览

| 参数 | 参数值 |
| --- | --- |
| 视频分辨率 | 4K 30 fps |
| 镜头模组 | 2000万像素传感器 + 广角镜头 |
| 照片分辨率 | 未提供照片档位；传感器像素不等于照片输出像素 |
| 显示屏 | 无；自动息屏设置的含义待确认 |
| 防抖 | 6轴陀螺仪 + EIS |
| 防水 | 主机裸机10 m；拓展舱不防水 |
| 存储 | 内置eMMC，默认64 GB；可定制32、128、256或512 GB |
| 视频模式 | 常规录像、循环录像、预录12秒 |
| 电池 | 主机500 mAh；拓展舱1300 mAh |
| 续航 | 主机120分钟以上；拓展舱230分钟以上；4K 30 fps、未开Wi-Fi |
| 重量 | 主机43 g；拓展舱100 g |
