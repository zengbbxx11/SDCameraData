# DC105PRO 5K候选规格

[[DC105PRO|返回产品]] · [[DC105PRO 技术规格|共有参数与海外8K完整规格]]

| 参数 | 5K候选值 |
| --- | --- |
| 传感器尺寸 | 1/2英寸 |
| 镜头视角 | 85° |
| 镜头参数 | F1.8±0.5%；f=4.7 mm |

| 5轴电子防抖 | 8K有记载；5K未提及 |
| 胶卷模式 | 8种 |
| TF卡上限 | 英文参数列1 TB；中文参数列512 GB，采用海外英文值，差异待确认 |
